# Caesar Cipher - Python

## About

This is a simple Python project that encrypts and decrypts text using the Caesar Cipher technique. The user can enter a message, choose whether to encrypt or decrypt it, and provide a shift value.

This project was built while learning Python basics such as functions, lists, loops, conditions, and string manipulation.

## Features

* Encrypt a message
* Decrypt a message
* User chooses the shift value
* Supports lowercase letters (a-z)
* Displays an ASCII art logo at the start
* Prompts the user to re-enter the message if an invalid character is entered

## Technologies Used

* Python 3

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python exercise.py
```

## Example
