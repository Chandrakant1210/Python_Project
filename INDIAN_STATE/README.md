# 🇮🇳 India States Guessing Game

An interactive Python game built using the **Turtle Graphics** module. The player enters the names of Indian states, and if the answer is correct, the state name is displayed at its correct location on the India map.

## 📌 Features

- 🎮 Interactive state guessing game
- 🗺️ Displays state names on a blank India map
- ✅ Validates user input
- 📍 Marks the correct state location using X and Y coordinates
- 📊 Uses a CSV file to store state names and map coordinates
- 🐢 Built with Python Turtle Graphics

## 📸 Demo

Enter the name of an Indian state.

Example:

```
Enter state name: Bihar
```

If the answer is correct, **Bihar** will appear on the map at its correct position.

## 🎯 How to Play

1. A blank map of India will appear.
2. Enter the name of an Indian state.
3. If your answer is correct:
   - The state name will be displayed on the map.
4. Continue until all **29 states** are guessed.

---

## 📊 Data Source

The project uses a CSV file containing:

- State Name
- X Coordinate
- Y Coordinate

These coordinates determine where each state name is displayed on the map.
